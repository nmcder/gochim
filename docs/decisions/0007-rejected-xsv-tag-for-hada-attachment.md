# 0007 — 접사 태그(XSV/XSA)로 `-하다` 붙이기를 시도했고 기각했다

- 상태: **기각**
- 날짜: 2026-08-27
- 관련: [0002](0002-precision-first.md), [0003](0003-three-layers-and-repo-split.md), [0006](0006-rejected-score-based-typo-detection.md)
- 재현: `npm run build && npm run guard` (아래 측정은 `data/golden` 전체 + 저장소 산문 2,209조각)

## 하려던 것

`-하다`는 접미사라 앞말에 붙여 쓴다. 그런데 말할 때 사이를 두는 버릇 때문에 적을 때도
띄우는 일이 아주 잦다 — `죄송 합니다`, `제출 하겠습니다`, `피곤 하네요`.

1층의 [seosul-hada](../../packages/core/src/rules/seosul-hada.ts)와
[seosul-hada-ext](../../packages/core/src/rules/seosul-ext.ts)가 이미 이 일을 한다.
관문도 잘 세워져 있다 — 뒷말이 정말 `하다`의 활용인지 **어미 허용 목록**으로 재고,
앞 어절이 관형어면 손대지 않는다. 둘 다 닫힌 집합이라 튼튼하다.

막힌 곳은 하나뿐이었다. **어떤 명사가 `-하다`를 받을 수 있는지를 손으로 적어야 했다.**
지금 103개가 적혀 있고, 그 밖은 영영 안 걸린다.

    제출 하겠습니다  → 목록에 있다  → 잡는다
    피곤 하네요      → 목록에 없다  → 못 잡는다

명사는 닫히지 않는 집합이라 이 목록은 끝나지 않는다. 그래서 **목록을 채우지 말고
문법 조건을 쓴다**는 원칙대로, 분석기의 접사 태그로 옮기려 했다.

    죄송 합니다  →  죄송/XR   합니다[하/XSA + ㅂ니다/EF]
    피곤 하네요  →  피곤/NNG  하네요[하/XSA + 네요/EF]

`하`가 **접미사(XSV·XSA)**로 읽혔다는 것은 앞말이 그 접미사를 받는 어근이라는 뜻이다 —
라고 생각했다. 그러면 목록이 하던 일을 태그 하나가 대신한다.

## 왜 안 되는가

**그 태그는 우리가 묻는 것을 모른다.**

분석기는 명사 뒤에 온 `하`를 거의 언제나 XSV로 붙인다. 그 명사가 서술성 명사인지를
따지지 않는다. 사전을 되물어 봐도 마찬가지다.

    제출 + 하다  →  제출/NNG + 하/XSV + 다/EF      ← 맞는 말
    두부 + 하다  →  두부/NNG + 하/XSV + 다/EF      ← 그런 말은 없다
    처음 + 하다  →  처음/NNG + 하/XSV + 다/EF      ← 그런 말도 없다
    소로 + 하다  →  소로/NNG + 하/XSV + 다/EF      ← 애초에 '소로'가 오분석이다

넷이 **글자 하나 다르지 않게 같은 꼴**로 나온다. 태그 뒤에 서술성 명사 사전이 없다.

관형어 판정(MM·ETM·JKG)까지 얹어 실제로 재 봤다. 깨끗해야 하는 글 2,209조각에서
**새 오탐 5건**, 표본 오류 529건에서 새로 잡은 것 **2건**.

    소로 하자.        →  소로하자.        (골든 함정: '돼지 말고 소로 하자')
    처음 해 보는 일   →  처음해 보는 일
    두부 한 모        →  두부한 모        ('한'을 하/XSV + ㄴ/ETM 으로 읽는다)
    가운데 하나가     →  가운데하나가
    다시 재야 한다.   →  다시 재야한다.   ('재야'를 명사로 읽는다)

10단계의 통과 조건은 **새 오탐 0건**이다. 넘었으므로 넣지 않는다.

## 좁히면 깨끗해지지만 닿는 데가 없다

앞말을 **XR(어근)**로만 좁히면 오탐이 0이 된다. XR은 홀로 설 수 없는 말이라
`두부·처음·소로`가 애초에 들어오지 않는다. 문법적으로 옳은 조건이다.

그런데 저장소가 가진 한국어 372조각을 통째로 훑어 XR로 읽힌 말은 **두 가지뿐이다** —
`익숙`, `애매`. 그 둘은 규칙이 제대로 잡는다. 다만 규칙 하나를 세울 값이 아니고,
더 나쁜 것은 **파일 이름과 주석이 "명사 목록을 대신한다"고 말하게 된다**는 점이다.
실제로 대신하는 것은 어근 두 개인데.

## 그래서 무엇을 하는가

**1층의 명사 목록을 그대로 둔다.** 닫히지 않는 목록인 것을 알지만, 지금 있는 것을
지우면 잡던 것까지 잃는다. 목록을 **더 채우지는 않는다** — 채울수록 `두부하다` 쪽
오탐이 함께 늘어나는 것을 위에서 봤기 때문이다.

이 자리는 서술성 명사 사전이 있어야 풀린다. 분석기가 주지 않으므로 우리가 갖거나
포기해야 하고, 지금은 포기한다.

## 남는 것

같은 10단계에서 **어미 쪽 신호 넷은 통과했다.** 그쪽은 태그가 우리가 묻는 것을
실제로 알고 있었기 때문이다.

| 신호 | 조건 | 새 오탐 |
| --- | --- | --- |
| `-구요` → `-고요` | `구/EC` + `요/JX` | 0건 |
| `-이여서` → `-이어서` | `이/VCP` + `여…/EC` + 앞 형태소에 받침 | 0건 |
| `-드-` → `-더-` | `드`로 시작하는 EC·EF | 0건 |
| `-을려고` → `-으려고` | `을려고/EC` (죽어 있던 가지) | 0건 |

가른 것은 **닫힌 집합이냐**다. 어미·조사는 닫혀 있어서 태그가 곧 답이지만,
명사는 열려 있어서 태그가 "명사다"까지만 말해 준다.
